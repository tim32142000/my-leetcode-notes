# Python int

## Python 處理 32 位元有號數

$-2^{31}$ <= result <= $2^{31} - 1$
```python
# Python 負數處理：
# 數字是 32 位元有號數，範圍是 -2^31 到 2^31-1
# 第 31 位是 1，代表它是負數
if result >= 2**31:
    result -= 2**32
```

## `!=` 錯用成 `is not` 有時候會運作正常

### 1. 小整數快取 (Integer Interning)：
在 Python 中，對於較小的整數（通常是 -5 到 256），Python 會預先建立物件並存放在記憶體中。這就是為什麼當整數較小時，is not 可能會「湊巧」運作正常，因為它們指向了同一個記憶體位址。

### 2. 大整數的問題：
當節點編號超過 256 時，Python 就會建立新的整數物件。此時，即使 a 和 b 的值是一樣的（例如都是 300），它們在記憶體中的位址卻不同。因此，is not 會判斷為 True，導致程式碼誤執行結果錯誤。
